+# v0.2 威胁清单
+
+日期：2026-10-11（Asia/Shanghai）。范围：已实现的 gateway TCP/WS、PacketCodec、Envelope、ConnectionRuntime/Feature 和 MessageRouter。其他服务、真实凭据认证与外部部署属于规划。源码基线 d5cf131；chaos 工具提交 8217f36/51aaeff。完整实测结果见 [30分钟报告](../reports/v0.2-chaos-20261011.md)。
+
+## 资产、入口与信任边界
+
+资产：连接/FD、队列与解析内存、owner线程可用性、会话状态、业务调用及错误/请求日志。外部输入跨越 TCP/HTTP/WS → Packet framing → protobuf → route/auth → Handler 五层边界。peer来自实际accept；Origin来自HTTP输入，不是身份。客户端时间和request id均不可信；deadline使用服务端steady_clock。
+
+测试宿主绑定loopback，不接触外部/生产服务。Packet echo profile只用于制造合法的大输出；不会将echo视为已认证业务。性能数据来自插桩宿主，不是生产容量承诺。

+## v0.2 判定边界
+
+0 crash/0 leak的验收是“本次完整窗口内无宿主意外退出或sanitizer诊断，逐轮FD回基线，六宿主正常退出并完成LeakSanitizer检查”。这是受测执行路径的证据，不是对所有输入、竞态、未来业务或部署环境的证明。
+
+v0.2标记当前传输/协议/chaos验收里程碑；开放威胁不通过本任务顺便实现。高优先后续顺序：真实认证与授权 → 登录/解析期限 → 共享IP与总资源准入 → TLS部署与日志资源策略。
